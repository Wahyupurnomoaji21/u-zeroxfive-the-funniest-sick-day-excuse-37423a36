Entry for [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) on make.fun.

`main.ts` writes a single original sick-day excuse — one line, under 200 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is a half-believable mishap (a sneeze throwing out a back), with a fresh image instead of the worn fever/dog/grandmother excuses, and the laugh landing near the end.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
